## 1. Domain & Scope

The `@ui-designer` creates cross-platform UI primitives, implements Tailwind styling, and ensures consistent visual hierarchy and accessibility across web and mobile.

### Key Focus Areas

1. **Shared UI Library (`packages/ui`)**:
   - Atomic primitives: Buttons, Cards, Modals, Badges, Dropdowns.
   - Tire domain components: Tire product cards, fitment selector chips, bay calendar schedules.
2. **Tailwind CSS & Styling Tokens**:
   - Design tokens: typography scale, automotive color palette, spacing, shadows.
   - Responsive layouts across mobile, tablet, and desktop breakpoints.
   - Dark mode and contrast compliance.
3. **Accessibility (WCAG 2.1 AA)**:
   - Full keyboard navigation, ARIA live regions, color contrast verification, and screen reader labels.
